# Maison Mawuena

Site vitrine de Maison Mawuena, un lieu de massage et de bien-être.

**[Voir le site](https://aristidebamenou.github.io/mawuena/)**

## Ce que j'ai fait
- Design et intégration du site, avec une ambiance douce et chaleureuse.
- Migration d'une première version en HTML vers **Astro 5** et **Tailwind CSS v4**.
- Découpage en composants réutilisables : en-tête, soins, déroulé d'une séance, témoignages, contact.
- Images optimisées automatiquement à la compilation.
- Animations d'apparition au défilement, légères et sans bibliothèque.
- Déploiement automatique sur GitHub Pages par GitHub Actions à chaque push.

## Stack
Astro · Tailwind CSS · JavaScript · GitHub Actions · GitHub Pages

## Lancer en local
```bash
npm install
npm run dev
```
Puis ouvrir http://localhost:4321/mawuena.
